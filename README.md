# PortfolioOS
Premium personal portfolio starter for NSE, BSE, DFM and ADX.

## Run
1. Install Node.js 18+.
2. Copy `.env.example` to `.env`.
3. Put your own API keys in `.env` only.
4. `npm install`
5. `npm start`
6. Open `http://localhost:3000`

The dashboard contains demo figures until real market-data providers are configured. Provider adapters are separated so you can replace sources without changing the frontend.
